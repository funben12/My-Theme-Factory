# My Theme Factory Skill

This skill provides a curated collection of 140 professional font and color themes, each with carefully selected color palettes and font pairings. Once a theme is chosen, it can be applied to any artifact.

## Purpose

To apply consistent, professional styling to any artifact — slide decks, reports, dashboards, HTML pages, documents, and more. Each theme includes:
- A cohesive color palette with hex codes
- Complementary font pairings for headers and body text
- A distinct visual identity suitable for different contexts and audiences

## Usage Instructions

To apply styling to an artifact:

1. **Show the theme list**: Present the categorised theme index below so the user can browse all 140 options. Do not reference the PDF — it only contains 10 themes and is outdated.
2. **Ask for their choice**: Ask which theme to apply, or ask about their context so you can suggest 2-3 suitable options.
3. **Wait for selection**: Get explicit confirmation about the chosen theme.
4. **Read the theme file**: Load the corresponding `.md` file from the `themes/` directory.
5. **Apply the theme**: Apply the selected theme's colors and fonts consistently throughout the artifact.

## Application Process

After a preferred theme is selected:
1. Read the corresponding theme file from the `themes/` directory
2. Apply the specified colors and fonts consistently throughout the artifact
3. Ensure proper contrast and readability
4. Maintain the theme's visual identity across all slides/sections

## Suggesting Themes

If the user is unsure, ask about their context (audience, tone, purpose) and suggest 2-3 options from relevant categories. For example:
- Corporate pitch → Enterprise, Professional, or Quiet Luxury
- Creative agency → Artistic, Expressive, or Neobrutalism
- Data dashboard → Dashboard, Material, or Nord
- Personal brand → Impeccable, Premium, or Editorial
- Dark/tech product → Dracula, Tokyo Night, or Synthwave 84

## Create Your Own Theme

When none of the existing themes work, create a custom theme. Based on inputs provided, generate a new theme matching the style of the existing files. Give it a name that describes the font/colour combination. Show it for review before applying.
